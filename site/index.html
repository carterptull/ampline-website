Amplify your status bar.

A zero-dependency Node.js statusline for Claude Code. Model, effort, context, usage limits, git, cost and PRs, color-coded on one line.

$ npx ampline-claude --install

Node.js ≥ 24 · 0 dependencies · no network · no credentials · MIT

● Works on macOS · Linux · Windows

Install

One command.

Run npx ampline-claude --install. It adds two entries to your Claude Code settings (statusLine and subagentStatusLine) and copies its runtime to ~/.claude/hooks/ampline-claude. Its small cache lives in ~/.claude/cache/ampline.

Undo any time: npx ampline-claude uninstall (backs up your settings first).

What it shows

Every signal, one line.

Each segment drops out cleanly when its data isn't there. On a narrow terminal the line splits into two instead of being cut off.

5-hour and weekly bars need a Claude.ai subscription. Requires a truecolor terminal.

Git and task samples use stand-in data with the real formatting; every other segment runs ampline's own code on a sample payload.

An optional .amplinerc.json in your project or home folder sets which segments show and in what order, the separator, where line 2 starts, and whether color is on or off.

Under the hood

Loud on screen. Quiet everywhere else.

01

Zero dependencies

One Node.js script. Nothing to audit but ampline itself.

02

No network, no credentials

Reads the JSON Claude Code pipes in, plus local git and todo files. Never reads credentials, never makes a network request.

03

Never breaks your session

Every segment fails silently. Cached git state, a hard timeout, always exits 0.

04

Escape-safe

Branch names, todo text and labels are sanitized before they reach your terminal.
